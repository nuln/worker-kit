# S3 跨云对象存储模块 (`@nuln/worker-kit/s3`)

[English](../en/s3.md) | [简体中文](./s3.md)

S3 模块为 Cloudflare Workers 提供了零外部依赖、原生 WebCrypto 驱动的 AWS SigV4 签名客户端，实现跨多云对象存储的无缝兼容。

## 适用厂商支持列表

- **Cloudflare R2** (`provider: "r2"`)
- **Amazon Web Services S3** (`provider: "aws"`)
- **MinIO / 本地开发 / 自建 S3** (`provider: "minio"`)
- **Wasabi Hot Cloud Storage** (`provider: "wasabi"`)
- **Backblaze B2** (`provider: "b2"`)
- **阿里云 OSS** (`provider: "oss"`)
- **腾讯云 COS** (`provider: "cos"`)

## 基础调用示例

```ts
import { createS3Client } from "@nuln/worker-kit";

const s3 = createS3Client({
  provider: "r2",
  endpoint: "https://<account-id>.r2.cloudflarestorage.com",
  accessKeyId: env.R2_ACCESS_KEY_ID,
  secretAccessKey: env.R2_SECRET_ACCESS_KEY,
  bucket: "production-bucket",
});

// 上传对象
await s3.putObject("logs/2026-09-17.json", JSON.stringify({ event: "boot" }), {
  contentType: "application/json",
});

// 下载对象
const response = await s3.getObject("logs/2026-09-17.json");
const data = await response.json();

// 生成预签名下载链接
const downloadUrl = await s3.getPresignedUrl("logs/2026-09-17.json", {
  method: "GET",
  expiresIn: 3600,
});
```
